# D.D 기획서 (최신 반영본)

## 1. 목적과 대상

- 나 혼자 사용하는 개인 작업 공간이다.
- 글쓰기, 뽀모도로, 투두리스트를 한곳에서 관리한다.
- 공개·발행·공유 기능은 제공하지 않는다.
- 파일을 연 브라우저의 로컬 데이터로 관리하며, 별도 로그인이나 서버 계정은 사용하지 않는다.

## 2. 화면 및 디자인

- 연회색 배경, 흰색 카드, 파란색 포인트 색상을 사용한다. 휴식 상태는 초록색, 삭제 동작은 빨간색으로 구분한다.
- 시스템 글꼴과 둥근 모서리를 사용하며 라이트 테마만 제공한다.
- 상단에는 D.D 로고만 표시한다. 로고는 D 글자 안에 귀가 처진 강아지의 얼굴·귀·눈·코를 단순화한 형태다.
- 글쓰기가 가운데 메인 영역이며, 뽀모도로와 투두 위젯은 오른쪽 고정 폭 패널에 둔다.
- 좁은 화면에서는 위젯이 글쓰기 아래로 이동하고 가로 스크롤이나 잘리는 버튼이 없어야 한다.

## 3. 글쓰기

- 제목과 본문은 분리되며 하루에도 여러 편 작성할 수 있다.
- 작성 날짜는 글을 처음 만든 날로 기록하고 사용자가 변경할 수 없다.
- 글 작성·수정·삭제·검색을 지원한다. 삭제는 확인 후 영구 삭제하며 복구 기능은 없다.
- 검색 대상은 제목, 본문, 메모, 카테고리 이름이다.
- 본문 서식은 굵게, 기울임, 문단 제목, 글머리 기호 목록, 글자 크기 조절을 지원한다.
- 글자 크기는 6~24px, 2px 단위이며 선택한 부분에 적용한다. 커서 위치에서 지정한 크기는 이후 입력에도 적용되어야 한다.
- 로컬 기기 또는 데스크톱에 저장된 이미지 파일을 선택해 본문에 삽입할 수 있다. 여러 이미지 선택을 지원한다. 이미지 데이터는 글 본문과 함께 브라우저 저장 및 JSON 백업에 포함한다.
- 이미지 파일은 브라우저에서 처리하며 크기가 큰 파일은 본문 저장 용량을 줄이기 위해 축소·압축할 수 있다.
- 카테고리는 사용자가 만들고 이름을 수정하거나 삭제할 수 있다.
- 카테고리는 큰 카테고리와 그 아래 소분류의 2단계 구조다. 글 하나에는 카테고리 하나만 지정하며 큰 카테고리 또는 소분류에 직접 지정할 수 있다.
- 글 목록은 카테고리별로 묶고 각 묶음 안에서는 최신 글이 위에 오도록 날짜순 정렬한다. 카테고리가 없는 글은 '미분류'에 표시한다.
- 카테고리 삭제 시 해당 글은 삭제하지 않고 미분류로 이동한다. 큰 카테고리를 삭제하면 하위 소분류도 삭제한다.
- 글 아래에는 작성 날짜와 시간이 표시되는 개인 메모를 추가할 수 있다. 메모는 수정·삭제 가능하며 수정한 메모에는 '(수정됨)'을 표시한다. 메모는 다른 사용자의 댓글이 아니다.

## 4. 저장 및 백업

- 글 편집은 기본적으로 수동 저장 모드다. 저장 버튼을 눌러야 글 변경 사항이 브라우저에 반영된다.
- 저장 버튼을 누르면 저장 완료 시각을 연·월·일 및 시·분 단위로 표시한다.
- 자동 저장은 사용자가 설정에서 직접 켤 수 있는 선택 기능이며 기본값은 꺼짐이다. 자동 저장을 켜면 변경 사항을 자동으로 저장한다.
- 수동 저장 모드에서 저장하지 않은 글을 이동하려는 경우 변경 사항을 저장할지 확인한다.
- 글, 메모, 카테고리, 투두, 장기 일정 및 뽀모도로 상태는 브라우저 로컬 저장소를 이용한다. 뽀모도로 상태는 새로고침 후에도 이어져야 한다.
- 내보내기는 JSON(.json) 파일로 글, 메모, 카테고리, 투두, 장기 일정을 백업한다. 글 본문에 삽입한 이미지도 포함한다.
- 불러오기는 파일 선택 후 덮어쓰기, 합치기, 취소 중에서 매번 선택한다.
- 덮어쓰기 전에는 기존 글·투두·메모·카테고리 등의 데이터가 대체된다는 경고를 표시한다.
- 합치기는 글 내부 ID가 같은 글이 이미 있으면 기존 글을 유지하고 없는 글만 추가한다. 내용이 같아도 ID가 다르면 별개 글로 취급한다. 카테고리·투두·장기 일정도 ID를 기준으로 중복을 피하며 기존 항목을 보존한다.

## 5. 뽀모도로

- 집중 25분이 끝나면 5분 휴식이 자동으로 시작된다. 시간은 고정이다.
- 휴식 5분이 끝나면 25:00 대기 상태로 멈추며 시작 버튼을 눌러야 다음 집중이 시작된다.
- 일시정지 후 계속을 누르면 남은 시간부터 재개한다.
- 초기화는 25:00 집중 대기 상태로 되돌린다.
- 집중 종료와 휴식 종료 시 모두 알림음을 낸다.
- 새로고침 후에도 진행 중이던 시간이 유지된다. 페이지가 닫혀 있는 동안 시간이 끝났다면 닫힌 상태에서 알림음을 보장하지 않으며 다시 열 때 경과 시간을 반영한다.

## 6. 투두 및 캘린더

- 투두의 기본 화면은 월간 캘린더다.
- 월 이동, 오늘로 이동, 날짜 직접 선택을 지원한다.
- 날짜를 선택하면 해당 날짜의 할 일 목록을 보고 새 항목을 추가할 수 있다.
- 투두 항목 수에는 별도 개수 제한을 두지 않는다.
- 완료 항목은 체크 시 같은 위치에 취소선으로 남으며 직접 삭제할 수 있다.
- 미완료 항목은 원래 날짜에 남고, 항목별 날짜 이동 기능으로 다른 날로 옮길 수 있다.
- 장기 일정은 시작일과 종료일을 갖는다. 캘린더에서 날짜를 드래그해 기간을 지정하고 이름을 입력해 추가할 수 있으며, 별도 일정 추가 기능으로 날짜를 직접 입력하는 방법도 제공한다.
- 동일한 장기 일정에 속하는 모든 날짜는 동일한 색으로 캘린더에 형광펜처럼 표시한다.
- 장기 일정의 이름과 기간을 수정하거나 삭제할 수 있다.
- 장기 일정은 JSON 내보내기·불러오기 대상에 포함한다.

## 7. 제외 기능 및 한계

- 위치 권한 요청, 현재 위치 조회, 가게·장소 검색 및 위치 정보를 글에 삽입하는 기능은 제공하지 않는다.
- 위치 또는 장소 검색을 위한 외부 API는 사용하지 않는다.
- 다크 모드, 뽀모도로 시간 변경, 투두 자동 이월, 글 휴지통·복구, 글 공개·발행 기능은 제공하지 않는다.
- 데이터는 파일을 연 브라우저에 저장되며 다른 기기나 브라우저와 동기화되지 않는다. 같은 브라우저라도 파일 위치나 브라우저 프로필이 다르면 데이터가 분리될 수 있다.
- 브라우저 데이터를 삭제하면 저장된 글과 일정이 사라질 수 있으므로 사용자가 JSON 내보내기로 직접 백업해야 한다.
- 잠금이나 비밀번호 기능은 없으며 같은 브라우저를 사용하는 사람은 데이터에 접근할 수 있다.
- 브라우저 저장 용량에는 한계가 있다. 특히 이미지가 포함된 글은 저장 공간을 더 사용한다.
- 기본 글쓰기·투두·뽀모도로·캘린더 기능은 단일 HTML 파일로 동작하도록 한다. 외부 네트워크나 로그인에 의존하지 않는다.

## 8. 완료 및 검증 기준

- 글을 여러 편 작성하고 수정·삭제·검색할 수 있다.
- 수동 저장 기본값에서 저장 버튼을 누르기 전 변경 사항이 저장되지 않으며, 저장 후 저장 시각이 표시된다.
- 자동 저장을 켜면 변경 사항이 자동 저장되고 새로고침 후에도 유지된다.
- 이미지 파일을 선택해 본문에 삽입하고 저장·새로고침 후에도 이미지가 표시된다.
- 카테고리를 만들고 수정·삭제할 수 있으며, 삭제된 카테고리의 글은 미분류로 이동한다.
- 메모를 추가·수정·삭제할 수 있고 수정 표시가 나타난다.
- 뽀모도로 집중 종료 후 휴식으로 전환되고, 휴식 종료 후 정지하며 일시정지·재개·초기화·새로고침 복원이 동작한다.
- 캘린더에서 날짜를 선택해 투두를 추가하고, 완료·삭제·날짜 이동할 수 있다. 항목 수 제한 없이 여러 항목을 관리할 수 있다.
- 캘린더 날짜 드래그로 장기 일정을 만들 수 있고, 기간 전체가 같은 색으로 표시된다. 일정 수정·삭제도 가능하다.
- JSON 덮어쓰기·합치기·취소가 의도대로 동작하고 글·이미지·메모·카테고리·투두·장기 일정이 복원된다.
- 좁은 화면에서 가로 스크롤이 생기거나 버튼이 잘리지 않는다.
- 위치 권한 요청이나 가게·장소 검색 기능이 노출되지 않는다.

## 9. 테스트 체크리스트

1. 글을 새로 작성하고 수동 저장 전·후 새로고침 동작을 비교한다.
2. 자동 저장을 켜고 글을 수정한 뒤 새로고침하여 변경 사항을 확인한다.
3. 사진을 한 장 및 여러 장 삽입하고 저장·새로고침·JSON 백업 복원 후 표시 여부를 확인한다.
4. 카테고리 생성·이름 변경·삭제 및 미분류 이동을 확인한다.
5. 메모 생성·수정·삭제 및 '(수정됨)' 표시를 확인한다.
6. 뽀모도로 종료 전환, 알림음, 일시정지·재개·초기화 및 새로고침 복원을 확인한다.
7. 달력 월 이동·오늘 이동·날짜 직접 선택과 날짜별 투두 추가·완료·삭제·날짜 이동을 확인한다.
8. 달력에서 여러 날짜를 드래그해 장기 일정을 만들고, 동일 색상 표시와 수정·삭제를 확인한다.
9. JSON 덮어쓰기와 합치기를 각각 실행해 기존 데이터 보존 및 신규 데이터 추가 규칙을 확인한다.
10. 좁은 화면에서 레이아웃과 버튼 표시를 확인한다.
11. 브라우저에서 위치 권한을 요청하지 않고 장소 검색 UI가 없는지 확인한다.
