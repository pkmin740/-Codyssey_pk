# D.D

## 대상 사용자

- 나 혼자 쓰는 개인 작업 공간. 공개나 발행 기능은 없고, 파일을 연 브라우저에서 나만 본다.

## 사용 목적

- 글쓰기, 뽀모도로, 투두리스트를 한곳에서 하는 개인 작업 공간

## 화면 구성과 동작

- **디자인**: 연회색 배경, 흰 카드, 파란 포인트 색(예외: 휴식 표시는 초록, 삭제 표시는 빨강), 시스템 글꼴, 둥근 모서리. 라이트 테마만 있다.
- **상단**: 로고만 있고 다른 글자나 소개 영역은 없다. 로고는 D 글자 안에 귀가 처진 강아지의 얼굴, 귀, 눈, 코만 단순하게 넣은 형태다.
- **배치**: 글쓰기가 가운데 메인 영역이고, 뽀모도로와 투두는 오른쪽의 고정 폭 위젯 패널이다. 폭이 좁은 화면에서는 위젯이 글 아래로 내려간다.
- **글쓰기**
  - 글은 제목과 본문이 따로 있고, 하루에 여러 편을 쓸 수 있다.
  - 글의 날짜는 작성한 날로 정해지고 바꿀 수 없다.
  - 저장 버튼 없이 입력하는 즉시 저장된다.
  - 글을 쓰고, 수정하고, 삭제하고, 검색할 수 있다. 삭제는 확인창 뒤 바로 영구 삭제이고 복구할 수 없다.
  - 검색은 제목, 본문, 메모, 카테고리 이름을 모두 찾는다.
  - 본문 서식: 굵게, 기울임, 제목(문단 단위), 글머리 기호 목록, 글자 크기(6~24px, 2 단위, 선택한 부분에만 적용)
  - 카테고리는 직접 만들고, 이름을 수정하고, 삭제할 수 있다.
  - 큰 카테고리 안에 소분류를 둘 수 있다(2단계까지). 글 하나에는 카테고리를 하나만 붙이고, 큰 카테고리에도 소분류에도 붙일 수 있다.
  - 왼쪽 목록은 카테고리별로 묶여 보이고(큰 카테고리, 그 안의 소분류), 각 묶음 안에서는 날짜순(최신 글이 위)이다. 카테고리가 없는 글은 "미분류"에 모인다.
  - 카테고리를 삭제하면 글은 지워지지 않고 미분류로 옮겨진다. 큰 카테고리를 삭제하면 그 소분류도 함께 삭제된다.
  - 글 아래에 날짜와 시간이 찍히는 메모를 덧붙일 수 있다. 메모는 수정과 삭제가 가능하고, 수정하면 "(수정됨)"이 표시된다. 메모는 나만 쓰는 덧붙임이고 다른 사람이 쓰는 댓글이 아니다.
- **뽀모도로**
  - 25분 집중이 끝나면 5분 휴식이 자동으로 시작된다. 시간은 고정이다.
  - 5분 휴식이 끝나면 25:00 상태로 멈추고, 시작 버튼을 눌러야 다음 집중이 시작된다.
  - 일시정지 후 "계속"을 누르면 남은 시간부터 이어간다. 초기화 버튼은 25:00 대기 상태로 되돌린다.
  - 집중이 끝날 때와 휴식이 끝날 때 모두 알림음이 난다.
  - 새로고침해도 진행 중이던 시간이 유지된다.
- **투두**
  - 날짜별로 정리되고, 날짜 이동 버튼이나 날짜 선택으로 다른 날을 볼 수 있다.
  - 완료한 항목은 체크하면 같은 자리에 취소선으로 남고, 직접 지울 수 있다.
  - 못 끝낸 항목은 그 날짜에 그대로 남고, 항목마다 "날짜 이동"으로 다른 날짜로 옮길 수 있다.
- **저장**
  - 글, 메모, 카테고리, 투두, 뽀모도로 상태가 브라우저에 자동 저장된다.
  - 내보내기는 글, 메모, 카테고리, 투두를 JSON(.json) 파일로 저장한다.
  - 불러오기는 파일을 고른 뒤 덮어쓰기, 합치기, 취소 중에서 매번 선택한다.
  - 덮어쓰기 선택창에는 "기존 글과 투두가 모두 사라져요(메모와 카테고리 포함)" 경고가 보인다.
  - 합치기는 같은 글(내부 번호가 같은 글)이 이미 있으면 기존 것을 그대로 두고, 없는 것만 추가한다. 내용이 같아도 번호가 다르면 다른 글로 본다.

## 필요한 자료

- D.D 로고 (직접 그림)

## 완료 기준

- 글을 쓰고, 수정하고, 삭제하고, 검색할 수 있다.
- 새로고침해도 글, 메모, 카테고리, 투두가 유지된다.
- 뽀모도로가 25분 후 5분 휴식으로 자동 전환되고, 휴식이 끝나면 멈춘다. 일시정지와 재개가 되고, 집중과 휴식이 끝날 때 알림음이 난다. 새로고침해도 남은 시간이 유지된다.
- 내보내기로 파일을 저장하고, 그 파일을 불러와 복원할 수 있다.
- 카테고리를 만들고, 수정하고, 삭제할 수 있으며, 글에 카테고리를 지정하면 목록에서 그 묶음 아래에 보인다.
- 메모를 추가하고, 수정하고, 삭제할 수 있다.
- 위의 디자인 기준대로 보이고, 폭이 좁은 화면에서 가로 스크롤이 없으며 버튼이 잘리지 않는다.
- 다른 파일이나 로그인 없이, 인터넷 연결 없이 HTML 파일 하나로 열린다. (최신 크롬, 사파리, 엣지 기준)

## 추가 기능

- 이후 구현할 기능은 나중에 정한다.

## 한계 및 비목표

1. 데이터는 파일을 연 브라우저에만 저장되어 다른 기기와 동기화되지 않는다. 파일 위치나 브라우저가 다르면 저장된 데이터가 따로 보인다.
2. 브라우저 데이터를 지우면 글과 투두가 사라질 수 있으므로 내보내기로 직접 백업해야 한다.
3. 잠금이나 비밀번호는 없다. 같은 브라우저를 쓰는 사람은 누구나 볼 수 있다.
4. 다크 모드, 뽀모도로 시간 변경, 투두 자동 이월, 글 휴지통(복구), 글 공개와 발행은 만들지 않는다.
5. 페이지를 닫아 둔 사이에 시간이 끝나면 알림음은 울리지 않고, 다시 열 때 지난 시간만큼 반영된다.

## 검증 방법

- 글, 메모, 카테고리, 투두를 만든 뒤 새로고침해서 그대로 남는지 확인한다.
- 뽀모도로를 시작해 25분(테스트 때는 시간을 줄여 확인)이 끝나면 소리가 나며 휴식으로 넘어가는지, 휴식이 끝나면 소리가 나며 멈추는지 확인한다.
- 뽀모도로를 시작하고 일시정지 후 재개했을 때, 그리고 새로고침했을 때 남은 시간이 이어지는지 확인한다.
- 메모를 수정하면 내용이 바뀌고 "(수정됨)"이 표시되는지 확인한다.
- 카테고리 이름을 바꾸거나 삭제한 뒤 삭제한 카테고리의 글이 미분류로 가는지 확인한다.
- 내보낸 파일을 다른 브라우저에서 불러와 글, 메모, 카테고리, 투두가 모두 복원되는지 비교한다. 덮어쓰기 경고 문구가 보이는지, 합치기에서 기존 글이 바뀌지 않고 없는 글만 추가되는지 확인한다.
- 폭이 좁은 화면에서 가로 스크롤이 생기거나 버튼이 잘리지 않는지 확인한다.
