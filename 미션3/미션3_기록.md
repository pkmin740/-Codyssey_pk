# 미션 3 기록

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| AI 검토 1: 저장 기능이 없어서 파일을 다시 열면 모든 영화가 미분류로 돌아간다 | 영화 몇 개를 등급 칸으로 옮기고 같은 파일을 다시 열었더니 모든 영화가 '아직 안 정한 영화'로 돌아갔다 | 반영 | 직접 해 보니 그렇고, 기획서 완성 기준 '같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다'를 지키지 못한다 |
| AI 검토 2: '처음으로'가 직접 추가한 영화를 지우지 않는다 | 영화를 하나 추가한 뒤 '처음으로'를 눌렀더니 추가한 영화도 사라지고 처음 영화 8개만 '아직 안 정한 영화'에 남았다 | 보류 | 직접 해 보니 AI의 말과 달랐다. 기획서 '처음 영화 8개가 모두 미분류로 돌아갑니다'대로 동작하므로 고칠 문제가 아니다 |
| AI 검토 3: 빈 제목을 막지 않아 글자 없는 카드가 생긴다 | 제목을 비워 두고 '추가'를 눌렀더니 글자 없는 빈 카드가 '아직 안 정한 영화'에 생겼다 | 반영 | 직접 해 보니 그렇고, 기획서는 제목을 입력하고 '추가'를 누르면 카드가 생긴다고 했으므로 제목 없는 카드는 약속에 맞지 않는다 |
| 동료 1: 휴대폰으로 열어 보니 좀 불편했다 | 브라우저 창을 좁혀 보니 오른쪽이 잘리는 것은 확인했지만, 동료가 말한 불편이 이것인지는 알 수 없다 (실제 휴대폰으로는 확인하지 못함) | 되묻기 | 무엇이 불편했는지 알 수 없어 확인할 수 없다. 질문: "휴대폰에서 어떤 화면이나 동작이 불편했나요? 오른쪽이 잘렸나요, 카드가 너무 컸나요, 옮기기가 어려웠나요? 쓰신 기기와 브라우저도 알려 주세요." |
| 동료 2: 카드 옮기는 게 처음엔 좀 헷갈렸다 | 카드를 끌어다 놓는 방법과 카드를 누른 뒤 등급 글자를 누르는 방법을 모두 해 봤더니 둘 다 옮겨졌고, 나는 헷갈리지 않았다 | 되묻기 | 어떤 부분이 헷갈렸는지 알 수 없어 확인할 수 없다. 질문: "끌어 놓기와 카드 누르고 등급 누르기 중 어느 쪽에서 무엇이 헷갈렸나요? 카드를 눌러도 반응이 없다고 느꼈나요, 끌어도 안 놓였나요?" |
| 동료 3: 끌어서 옮기기가 불편하다. 안 정한 영화가 맨 아래라 S칸까지 끌려면 화면을 같이 올려야 한다. 영화 목록이 위나 옆에 있으면 좋겠다 | 안 정한 영화를 끌어서 S칸에 놓으려 했더니 화면을 같이 올려야 했다. 카드를 누르고 등급 글자를 누르는 방법으로도 옮겨졌다 | 보류 | 기획서가 '위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드'로 배치를 정해 두었으므로 목록을 위나 옆으로 옮기는 것은 기획서와 부딪힌다. 끌기 말고 누르는 방법도 있다 |
| 동료 4: 카드 색이 좀 칙칙한 느낌이다 | 카드를 보니 회색 계열이었다 | 보류 | 취향의 문제이고, 기획서에 카드 색 조건이 없어서 꼭 바꿀 이유가 없다 |
| 동료 5: 영화 포스터 사진이 같이 나오면 좋겠다 | 카드에 영화 제목만 나오고 포스터는 없었다 | 보류 | 기획서의 필요한 자료는 영화 제목뿐이고, 완성 기준에 '외부 파일이나 로그인 없이 HTML 한 장으로 열립니다'가 있어서 포스터를 넣으면 기획서와 부딪힐 수 있다 |
| 동료 6: C칸은 굳이 없어도 될 것 같다 | S·A·B·C 네 칸이 있고 C칸에도 영화를 놓을 수 있었다 | 보류 | 기획서의 목적이 '본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리'하는 것이라 C칸을 없애면 기획서와 부딪힌다 |

- 아무도 말하지 않았는데 내가 찾은 것:
  - 브라우저 창 폭을 줄였더니 화면 오른쪽이 잘려서 보이지 않았다. 기획서 완성 기준 '화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다'를 지키지 못한다. AI 검토는 "이 세 가지 외에는 잘 지킨다"고 했고, 동료는 휴대폰이 불편하다고만 했을 뿐 이 내용을 구체적으로 말하지 않았다.
  - 같은 제목을 여러 번 입력하고 '추가'를 눌렀더니 같은 영화 카드가 계속 생겼다.
  - 빈 카드나 잘못 추가한 카드를 하나씩 지울 버튼이 없어서, 없애려면 '처음으로'를 눌러야 하고 그러면 옮겨 둔 영화까지 모두 처음 상태로 돌아간다.
  - 영화 카드가 제목만 있는데도 한 장이 차지하는 칸이 커서, 영화가 늘어나면 화면을 많이 내려야 했다.
