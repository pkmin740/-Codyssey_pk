# 코디세이 도우미

> 정하지 않은 내용은 **⚠️ 미정**, 제안만 한 내용은 **💡 제안(확정 아님)** 으로 표시했습니다.

## 대상 사용자

- 50~70대 사용자, 컴퓨터 경험은 사람마다 제각각
- 아이맥 화면을 보면서 따라 하는 사람 (macOS Sequoia 15.7.4)
- 스마트폰은 지원하지 않음

## 사용 목적

- 아이맥 기초 사용법, 바이브코딩의 코딩 단계에서 필요한 부분(바로가기·막혔을 때 질문법·용어 설명), 오류가 났을 때 AI에게 질문하는 법을 **균형 있게** 알려 준다
- 오류 범위는 아이맥 자체 문제와 바이브코딩 중 오류 둘 다
- 사용자가 다음을 할 수 있게 한다
  - 혼자서 아이맥을 켜고 기본 설정까지 한다
  - 바이브코딩 도중 필요한 바로가기·용어·질문법을 찾아 쓴다
  - 막혔을 때 AI에게 스스로 질문해 해결한다
- 링크만 공유하는 무료 공개 사이트 (운영 비용 0원, 공유 링크로 공개)

## 화면 구성과 동작

**화면**

- 첫 화면에 큰 버튼 3개: ① 아이맥 기초 사용법 ② 바이브코딩 바로가기 ③ 오류 해결 질문법
- 버튼을 누르면 영역 안 메뉴가 나오고, 메뉴 한 개가 설명 한 개(= "항목")다. 영역마다 항목 3~4개

| 영역 | 항목 |
|---|---|
| 아이맥 기초 (4개) | 켜고 끄는 방법 / 한글·영어 입력 전환 설정(시스템 설정에서 한글 키보드 설정하는 법 포함) / 글자·화면 크기 키우기 / 간단한 단축키 |
| 바이브코딩 바로가기 (4개) | Claude / ChatGPT / Gemini / 코딩 도구(Cursor·VS Code를 한 항목으로 묶음) |
| 오류 해결 질문법 (4개) | 코딩 중 막혔을 때 AI에게 질문하는 법 / 아이맥 문제가 생겼을 때 질문법 / 오류 질문 만들기 / 자주 묻는 질문(FAQ) |

- 글자 크기 조절 버튼 3단계(보통 · 크게 · 아주 크게), 기본값은 '크게'. 도움말 속 작은 글씨도 같이 커진다
- 설명은 사진 없이 글과 간단한 그림·아이콘으로 한다

**동작**

- 바로가기를 누르면 **새 창**으로 열린다 (사이트 안의 용어도 '새 창'으로 통일)
- 따라 하기 설명의 단계마다 체크 표시를 할 수 있다. 체크 기억 기능은 선택하지 않아, 다시 열면 체크는 처음 상태로 돌아간다
- 예시 질문 문장은 '복사' 버튼으로 복사한다
- 어려운 용어 옆 '?' 버튼을 누르면 설명이 뜬다
- **오류 질문 만들기** (API·AI 연동 없이 동작)
  1. 오류 상황 버튼을 고른다
     - 아이맥 문제: 프로그램이 안 열려요 / 화면이 멈추거나 느려요 / 키보드에 한글이 안 돼요 / 경고 메시지가 길게 뜨고 끌 수 없어요
     - 코딩 문제: 빨간 글씨 오류 메시지가 나왔어요 / AI가 엉뚱한 답을 해요 / 작업하던 내용이 사라졌어요
  2. 오류 문구나 상황을 한두 줄 직접 적는다 (선택)
  3. 입력 내용이 끼워진 예시 질문이 만들어진다
  4. '복사' 버튼으로 복사한다
  5. 캡처 사진은 사이트가 읽지 않고, 사용자가 복사한 질문과 함께 AI 채팅창에 직접 붙여넣는다
  6. 사이트에 캡처 방법(Shift+Command+4)과 붙여넣기 방법을 그림·아이콘으로 안내하고, AI 채팅 바로가기를 새 창으로 연다

💡 제안(확정 아님): "경고 메시지가 길게 뜨고 끌 수 없어요" 안내에, 경고 화면에 나온 전화번호로 연락하지 않도록 알리는 문구를 넣는다. 가짜 경고창일 가능성이 있기 때문이다.

💡 제안(확정 아님): '복사' 버튼이 브라우저 환경에 따라 막힐 수 있으므로, 막히면 질문 글자를 직접 선택해 복사하도록 안내한다.

⚠️ 미정: 첫 화면 큰 버튼 문구, 색상·디자인 분위기

## 필요한 자료

- 아이맥 기초 사용법 설명: 준비된 것이 없어 **처음부터 작성** (macOS Sequoia 15.7.4 기준)
- 바로가기 대상: Claude, ChatGPT, Gemini, 코딩 도구(Cursor·VS Code)
- 용어 설명: '?' 도움말로 표시. 예시 용어는 터미널, 프롬프트, 독
- FAQ: 질문법 + 아이맥 기초 관련 질문까지
- ⚠️ 미정: 단축키 구체 목록, FAQ 질문 목록, 도움말을 붙일 용어의 전체 목록과 위치, 바로가기 링크의 정확한 주소, "코딩 도구" 항목 안에서 두 도구를 보여 주는 방식
- ⚠️ 확인 필요: 설명 속 메뉴 이름이 실제 아이맥 화면과 맞는지는 사이트를 만든 뒤 직접 따라 해 보며 확인해야 한다

## 완료 기준

- 첫 화면의 큰 버튼은 세지 않고, 그 뒤로 **3번 클릭 이내**에 원하는 설명에 도착한다. 확인 범위는 영역마다 대표 설명 1개씩, 총 3개다
- ⚠️ 미정: 영역별로 어떤 설명을 대표로 삼을지
- 꼭 지켜야 할 조건
  - 로그인·회원가입 없이 쓸 수 있다
  - API와 AI 연동 없이 동작한다
  - 운영 비용 0원으로 공유 링크로 열린다 (⚠️ 확인 필요: 공유 링크 공개가 실제로 되는지는 만들 때 확인)
  - 다른 파일이나 로그인 없이 **HTML 파일 하나로 열린다**

## 추가 기능

- 자주 묻는 질문(FAQ) 모음 (질문법 영역의 항목). 만들지 않아도 질문법 영역은 3개 항목이 남는다
- 이번에 선택하지 않은 후보 (이후 구현 여부는 정하지 않음): 체크한 단계 기억하기, 인쇄해서 볼 수 있는 보기

## 한계 및 비목표

1. 로그인·회원가입 기능은 만들지 않는다
2. 아이맥 외 기기(윈도우·맥북) 설명은 하지 않는다
3. 광고·결제·후원 기능은 만들지 않는다

참고: API와 AI 연동을 쓰지 않으므로 사이트가 캡처 사진 속 내용을 직접 읽지는 못한다. 스마트폰 화면은 지원하지 않는다. 이미지 첨부는 AI 서비스·요금제에 따라 제한될 수 있어 안내 문구에 반영해야 한다.

## 검증 방법

직접 만든 체크리스트로 점검한다. 사이트가 완성되면 **아이맥 화면에서 직접** 열어 확인한다. (점검 날짜: ________ / 브라우저: ________)

**필수 기능 (2개)**

- ☐ **1. 3번 클릭 도착**: 영역마다 대표 설명 1개씩, 첫 화면 버튼 이후 3번 이내에 도착한다.
  - 아이맥 기초: ______________ → ___ 번
  - 바로가기: ______________ → ___ 번
  - 질문법: ______________ → ___ 번
- ☐ **2. 오류 질문 만들기**: 상황 버튼을 고르면 질문이 만들어지고, '복사' 버튼으로 복사해 다른 곳에 붙여넣으면 그대로 나온다. 아이맥 문제 버튼 1개, 코딩 문제 버튼 1개로 확인한다.

**추가 기능 (1개)**

- ☐ **3. FAQ**: 질문법 영역 안에서 FAQ가 열리고, 질문을 눌러 답을 볼 수 있다.

**판정**: 필수 2개가 모두 통과이면 완료로 본다. FAQ가 실패하면 번호를 적어 두고, 고친 뒤 그 항목만 다시 확인한다.

- 실패 기록: ______________________________
