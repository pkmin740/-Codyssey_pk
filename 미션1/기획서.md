
# 🎬 영화 티어리스트 제작 기획서 (최종)

### 1. 누가 쓰나
*   **사용자**: 개발자 본인 (1인용 개인 웹페이지)

### 2. 무엇을 하려고
*   직접 본 영화들을 4단계 등급으로 분류하고 시각적으로 관리하기 위함

### 3. 화면과 동작
*   **화면 구성**
    *   **전체 테마**: 어두운 다크 테마
    *   **티어 구역**: 왼쪽/중앙에 4단계 등급(인생영화, 추천, 볼만함, 비추천) 배치
    *   **사이드바**: 화면 오른쪽에 '분류 전 목록' 배치
*   **주요 동작**
    *   **드래그 앤 드롭**: 영화 아이템을 마우스로 끌어서 각 티어 영역으로 이동
    *   **영화 추가**: '추가하기' 버튼을 누르면 팝업창이 뜨고, 제목과 이미지 주소(URL)를 입력하여 생성

### 4. 필요한 자료
*   **영화 데이터**: 영화 제목, 영화 포스터 이미지의 웹 주소(URL)
*   **기술 스택**: HTML, CSS, JavaScript (데이터 저장을 위한 LocalStorage 활용)

### 5. 완성 기준
*   **드래그 앤 드롭**: 영화 포스터가 각 티어 칸으로 정상적으로 이동하고 배치되는가?
*   **데이터 유지**: 웹페이지를 새로고침해도 추가한 영화와 배치된 위치가 그대로 유지되는가?
*   **디자인**: 설정한 다크 테마 디자인이 화면에 깔끔하게 구현되었는가?
*   **입력창 제어**: **영화 추가 입력창이 평소에는 숨겨져 있다가, 추가할 때만 화면에 나타나는가?**

---

### 💡 아직 정해지지 않은 것
*   **영화 삭제/수정 기능**: 등록된 영화를 삭제하거나 내용을 수정하는 기능
*   **티어별 상세 색상**: 각 등급(인생영화~비추천)을 상징하는 구체적인 포인트 컬러
*   **모바일 최적화**: 스마트폰 환경에서의 화면 배치(반응형 디자인)
